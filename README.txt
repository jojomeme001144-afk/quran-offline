القرآن الكريم PWA v4
====================

- القرآن كامل للقراءة والبحث بدون إنترنت.
- اختيار القارئ من الواجهة الرئيسية.
- قائمة القراء تُحدّث من MP3Quran وتُحفظ محليًا بعد أول اتصال.
- لكل قارئ تظهر أنواع التلاوة المتاحة (ترتيل / تجويد / روايات أخرى) كمصادر مستقلة.
- القراء الإضافيون محفوظون في البرنامج: وليد إبراهيم الفلوجي، عبد الرحمن مسعد، عامر الكاظمي عند عدم وجودهم بالمصدر الرئيسي.
- تنزيل التلاوة الحالية كاملة للاستخدام بدون إنترنت مع إمكانية الإكمال لاحقًا.
- حفظ سورة منفردة، وحفظ الآية كنص أو صورة.
- خيار تحسين وضوح خفيف للملفات الصوتية المحفوظة، مع رجوع طبيعي إذا لم يدعم الجهاز المعالجة.
- تثبيت PWA على الشاشة الرئيسية.

مهم: التثبيت وService Worker يحتاجان فتح البرنامج من موقع HTTPS مثل GitHub Pages، وليس file://.
